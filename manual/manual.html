CHAPTER 01

Introduction

The Flight Attendant Panel (FAP) is the cabin crew's control centre on the Airbus A320. It is part of the CIDS, the Cabin Intercommunication Data System, and it is usually installed at the forward attendant station near door L1.

From the FAP the cabin crew controls and monitors the cabin lighting, announcements and boarding music, doors and escape slides, cabin temperature, potable water and waste, lavatory smoke detection and passenger calls. The A320 FAP Simulator reproduces the panel on an Android tablet so students can practise every function in the classroom.

How the panel is organized

  • Touchscreen: the upper part. It shows the header, the page title bar, the selected page and two rows of page tabs.
  • Hard keys: ten physical keys below the screen (EVAC, lighting, smoke reset, and more). They keep working even while the touchscreen is locked. See Chapter 14.
  • Memory card slots: PRAM (pre-recorded announcements), CAM (cabin assignment module) and OBRM (on-board replaceable module, for software loading).

Color conventions

The simulator follows the real A320 CIDS color logic:

ColorMeaning
GREYKey available, not selected.
GREENSelected / active (for example the light level in use, or the open page).
AMBERCaution: something needs attention (passenger call, waste tank full, smoke being monitored).
REDAlarm: immediate action (smoke, slide deployed, evacuation). Red items flash.

TRAINER boxes

Controls inside a dashed cyan box labelled TRAINER are not part of the real FAP. They let the instructor simulate what happens away from the panel, such as a passenger pressing a call button, smoke appearing in a lavatory, the crew moving a door arming lever, or the flight crew changing a cockpit selector. Everything outside these boxes behaves like the aircraft panel.

TIPUse the TRAINER controls to create a situation, then let the student respond using only the real FAP keys.
CHAPTER 02

Getting Started

Installing the app

  1. On the website, scan the QR code with the tablet camera or tap DOWNLOAD APK.
  2. When Android asks, allow Install unknown apps for your browser, then install.
  3. Open A320 FAP and hold the tablet in landscape. The app runs full screen.

Requirements: Android 7.0 or newer. A landscape tablet is recommended.

Activating with a license code

  1. Connect the tablet to the internet (needed once, for activation only).
  2. Type your license code exactly as given, for example A320-k7Rm9Qx2. Codes are case-sensitive: capital and small letters matter.
  3. Tap ACTIVATE. After activation the simulator works fully offline.
  • Each code works on one device only and can never be used on another device.
  • Reinstalling is safe. If the app is uninstalled and installed again on the same tablet, it recognizes the device and unlocks automatically (online) without a new code. If the tablet is offline at that moment, connect it and tap CHECK AGAIN.
  • A factory reset of the tablet counts as a new device: move the license first (see below), or ask the administrator to release it.

Moving your license to a new tablet

  1. On the old tablet, connected to the internet, tap the gear icon in the top-right corner of the screen.
  2. Settings shows your license code, the device ID and the activation date. Write down the code.
  3. Tap DEACTIVATE & TRANSFER LICENSE and confirm. The old tablet locks and returns to the activation screen.
  4. On the new tablet, enter the same code and tap ACTIVATE.
OLD TABLET BROKEN OR LOST?Ask your instructor or administrator to release your code from the admin panel, then activate it on the new tablet. If the old tablet ever comes back online, it locks itself automatically.

Free demo

Without a license code you can try the simulator: tap TRY DEMO on the start screen, or enter the demo code A320-DEMO. No internet is needed.

The demo includes one lighting function (MAIN ON/OFF on the Cabin Lighting page) and one audio function (boarding music ON/OFF on the Audio page), plus the LIGHTS and AUDIO page tabs. Touching any other key, page or hard key opens the Enter the license code window. Enter a license code there, or with the ENTER LICENSE CODE button in the bar, to unlock every function at once.

Important notice

At every start the app shows the Important Notice & Disclaimer (see Chapter 17). Read it and tap I AGREE & CONTINUE to open the panel.

CHAPTER 08

Cabin Temperature

The flight crew selects each zone temperature in the cockpit; the cabin crew can fine-tune it from the FAP.

  • Cockpit selection: 18 °C to 30 °C per zone (FWD and AFT). The TRAINER cockpit zone temperature selectors (− / +) simulate the flight crew changing it.
  • FAP fine adjustment: − / + moves a zone up to ±2.5 °C around the cockpit selection. The indicator shows the offset.
  • ACTUAL: the measured zone temperature. It moves gradually toward the target as the air-conditioning packs respond.
  • RESET TO COCKPIT SELECTED TEMP removes all FAP adjustments.
  • Switch between °C and °F with FAP CONFIG.

CHAPTER 10

Smoke Detection

Smoke detectors in lavatories A (forward), D (aft left) and E (aft right).

  • On a smoke alert the SMOKE DETECTION page opens automatically, an aural alert sounds, the message line shows SMOKE LAV D and the tab flashes red.
  • SMOKE RESET (on this page or the hard key) silences the aural alert and the cabin indications.
  • The FAP keeps showing the smoke for as long as the detector still senses it.
  • Once no more smoke is detected, the CIDS clears everything automatically.

TRAINER

SMOKE makes smoke appear in that lavatory; EXTINGUISH simulates the fire being put out (smoke cleared).

LAV SMOKE – CREW ACTIONS

  1. Press SMOKE RESET to silence the aural alert.
  2. Go to the lavatory. Feel the door with the back of your hand before opening.
  3. Locate the source. If fire: get the nearest extinguisher and fight it.
  4. Inform the cockpit immediately (interphone).
  5. Keep the door closed after extinguishing; monitor for re-ignition.
  6. When no more smoke is detected, the CIDS clears all indications.
REMEMBERAlways follow your airline cabin crew manual.

CHAPTER 12

System Info

CIDS health and messages, plus trainer fault injection and cockpit events.

  • CIDS SYSTEM STATUS: the two CIDS directors (DIR 1 / DIR 2) and which one is active, PAX SYS, the EVAC selector position (CAPT or CAPT & PURS) and the FAP software version.
  • MESSAGES: current CIDS messages and faults.

TRAINER – fault injection

DIR 1 FAULT / DIR 2 FAULT fail a director; the other takes over (amber). With both failed the cockpit ECAM shows CIDS 1+2 FAULT: PA announcements, interphone and passenger signs are lost and the SYSTEM INFO tab turns red.

TRAINER – cockpit / automatic events

ControlSimulates

COCKPIT EVAC CMDThe flight crew sets EVAC COMMAND ON: EVAC COMMANDED FROM THE COCKPIT.
LOW CABIN PRESSURELow cabin pressure: the CIDS switches the cabin lights to BRT automatically.

CHAPTER 13

CAM & Maintenance Pages

The second row of tabs holds the cabin programming and maintenance pages. Most of them are protected by an access code.

PageAccess code (CIDS default)
CABIN PROG, LAYOUT SELECT, LEVEL ADJUST318
SW LOAD813
FAP SET-UPNo code

The codes are also shown in the TRAINER box of the keypad. FAP RESET locks the protected pages again.

Cabin Programming

  • CABIN ZONES: choose a class boundary and move it by seat rows with the arrow keys; the cabin drawing shows each class with its seat rows.
  • NON SMOKER A/C ON/OFF: the non-smoking aircraft flag.
  • SAVE writes the programming to the CAM. The layout becomes MODIFIED and its change counter goes up.

Layout Selection

Select a 1-, 2- or 3-class layout and press LOAD to make it active. The lighting zones, seat rows and level adjustment follow the active layout.

Level Adjustment

Announcement and chime loudspeaker levels per cabin zone, attendant area and lavatory, from −6 to +6 dB. Press ADJUST on a group (cabin zones, attendant areas or lavatories) to show it, pick an area with the arrow keys, and set its ANNOUNCE and CHIME levels with + / −. DEFAULT returns the group to +0 dB; SAVE stores the levels. Cabin zone levels change how loud PA announcements and chimes play in the simulator.

Software Loading

Lists the CIDS components with the active software version and the version on the OBRM card in the slot. Amber: a different version is waiting to be loaded. Green: up to date. LOAD SW loads it; the panel is blocked during loading and the CIDS restarts automatically.

FAP Set-Up

DISPLAY brightness, loudspeaker and headphone VOLUME (+ / −), and the TOUCHSCREEN CLICK (ON/OFF). DEFAULT restores the factory values and SAVE stores them.

CHAPTER 15

Training Drills

Suggested classroom exercises. The instructor creates the situation with the TRAINER controls; the student responds with the FAP keys only.

Drill 1 – Boarding

  1. LIGHTS: GENERAL BRT, MAIN on, ATTND on.
  2. AUDIO: select a music channel and press ON/OFF; adjust VOL.
  3. When boarding is complete, play 010 Welcome aboard with DIRECT PLAY, then stop the music.

Drill 2 – Arm slides and cross-check

  1. Instructor: ARM SLIDES X-CHECK (or arm individual doors with AT DOOR).
  2. Student: open DOORS/SLIDES and confirm every door shows CLOSED + ARMED (green).
  3. Report any door not armed; the message line reminds Please check door/slide status prior departure.
  4. Press CABIN READY once the cabin is secured.

Drill 3 – Pre-departure announcements

  1. AUDIO: add 020, 040 and 050 to MEMO with ←; order them with ▲ / ▼.
  2. Press PLAY ALL, or PLAY NEXT one at a time.
  3. LIGHTS: set DIM 2 for a night take-off.

Drill 4 – Lavatory smoke

  1. Instructor: SMOKE DETECTION TRAINER SMOKE on a lavatory.
  2. Student: the page opens automatically; press SMOKE RESET.
  3. Follow the six crew actions (Chapter 10) and inform the cockpit.
  4. Instructor: EXTINGUISH; the CIDS clears the alert automatically.

Drill 5 – Evacuation

  1. Instructor: set the selector to CAPT & PURS (SYSTEM INFO), or use COCKPIT EVAC CMD.
  2. Student: lift the guard and press EVAC CMD. The evacuation alert sounds and the title bar flashes red.
  3. Press EVAC RESET to silence the tone at this station.
  4. Repeat with the selector in CAPT: only the cockpit horn sounds for 3 s.

Drill 6 – Slide deployment

  1. With slides armed, the instructor opens a door with AT DOOR OPEN.
  2. Student: identify the red SLIDE DEPLOYED alarm and the door concerned, and report it.
  3. Instructor: RESET DRILL.

Drill 7 – Passenger call and seat inhibit

  1. Instructor: PASSENGER PRESSES CALL several times.
  2. Student: read the seats on the message line or the Audio page, answer them, then CALL RESET.
  3. Inhibit the call button of a "broken" seat on SEAT SETTINGS.

Drill 8 – Water / waste and CIDS faults

  1. Instructor: ADD WASTE +10% until the tank is full; student identifies the INOP lavatories and presses RESET WARN.
  2. Instructor: DIR 1 FAULT, then DIR 2 FAULT; student explains the CIDS 1+2 FAULT consequences (no PA, interphone or signs).

Common questions

Do I need internet in the classroom?

No. Internet is needed only once, to activate the license code. After that the simulator runs fully offline.

I uninstalled the app. Do I need a new code?

No. Install it again on the same tablet and open it while online; it is restored automatically. A factory reset counts as a new device.

I have a new tablet. Can I keep my code?

Yes. On the old tablet open Settings (gear icon) and tap DEACTIVATE & TRANSFER LICENSE (internet needed), then enter the same code on the new tablet. If the old tablet is broken, ask the administrator to release the code.

The app went back to the activation screen by itself.

The license was moved to another device (deactivated there or released by the administrator). Enter a valid code to activate again.

A page asks for an access code.

CABIN PROG, LAYOUT SELECT and LEVEL ADJUST use 318; SW LOAD uses 813.

The screen is black.

SCREEN OFF is active: touch the screen to wake it. During SCREEN 30 SEC LOCK, wait for the countdown.

There is no sound.

Check the tablet volume, MUTE in FAP CONFIG, CHIME INHIBIT, the loudspeaker volume in FAP SET-UP, and the levels in LEVEL ADJUST.

How do I start a drill again from the beginning?

Use RESET DRILL on the Doors page, or RESET SIMULATOR on SYSTEM INFO to restore all factory defaults.
